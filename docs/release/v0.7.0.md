# 题灵 Quizora v0.7.0

> 发布日期：2026-11-02 · 类型：新功能（头歌编程作业）

## 为什么做这个版本

头歌（EduCoder）编程作业是“左侧任务说明 + 右侧 Monaco 编辑器 + 右下角评测”的形态，老师会禁用粘贴。原有整卷答题链路只处理选择题/填空/简答，无法完成编程关卡。

## 调研结论

- **编辑器**：头歌使用 **Monaco Editor**。公开的 MIT 脚本《学习通 / 头歌 Pro》通过 `monaco.editor.getModels()[0].setValue(code)` 写入，说明主 world API 可绕过 DOM 的禁用粘贴限制。
- **页面结构**：`EduCoder Helper`（AGPL，仅作行为参考，未复制代码）使用 `window.taskId`、`window.taskChallengePath` 与 `data.educoder.net/api/tasks/...` 读写文件；其“解除粘贴/导出代码”能力证明页面存在 Monaco 与任务文件模型。
- **评测流程**：官方学生手册说明“补充代码 → 点击评测 → 失败展开测试集查看错误详情”，与用户描述一致。

## 0.7.0 实现

1. 静态内容脚本注入 `*.educoder.net`（`all_frames`），支持直接打开与学习通内嵌 iframe。
2. `edu-adapter.js`：
   - 读取左侧“任务描述”文本；
   - 按文本查找“评测 / 下一关 / 下一题 / 继续”按钮；
   - 读取“测试结果”面板，按关键词判定通过/失败；
   - 用文本 + 左右布局启发式，避免绑定具体 class；
   - 考试页保护：URL 含 `/exam` 或页面出现“交卷/监考/考试剩余时间”时拒绝。
3. `edu-main.js`：
   - 通过 background `EDU_STATE` 读取 Monaco 模型与语言；
   - `EDU_SOLVE` 调用新提示词 `askCode`，要求输出**完整代码**并保留模板标记；
   - `EDU_SET_CODE` 在主 world 执行 `model.setValue(code)`；
   - 点击“评测”，轮询结果；失败把测试集/错误详情回传给模型修复，默认最多 3 次；
   - 自动等待平台约 20 秒冷却（按按钮 disabled/文案状态）；
   - 通过后点击“下一关/下一题/继续”，继续下一关；
   - `sessionStorage` 保存 `{settings, passed}`（不含 API Key），整页刷新后自动续跑。
4. 后台新增 `EDU_STATE` / `EDU_SET_CODE` / `EDU_SOLVE`；评测失败以 `WG_STOPPED reason=failed` 上报，面板显示“未通过”。

## 验证

本地 headless Edge mock（5 条路径，全部符合预期）：

| 路径 | 结果 |
| --- | --- |
| 两关正常通过（含一次失败重试） | 第 1 关失败→冷却→第 2 次通过→下一关；第 2 关通过；状态“已完成” |
| 连续失败达到上限 | 2 次尝试后停止，状态“未通过” |
| 演练模式 | 只生成代码，不写入/不评测，提示关闭演练 |
| 考试页 | `count=0`、`blocked=true`，启动即拒绝 |
| 结果面板解析 | 正确识别“恭喜您，本次评测通过”与“未通过…测试集1失败” |

## 使用

1. 打开头歌任务页（可直接打开，也可在学习通内嵌页）。
2. 侧边栏 **关闭“演练模式”**，点“开始”。
3. 插件会自动生成、写入、评测、重试并进入下一关。
4. 若停在某一关：看日志 `评测返回：…`，把原文发回；或在探测快照中查看 `buttons/result/hasEditor/hasEvaluate`。

## 已知限制

- 真实头歌页面的按钮/结果文案尚未真机验证；当前按文本+布局启发式匹配。
- 只填充 Monaco 主文件；多文件任务后续再支持。
- 头歌考试页不自动作答（硬约束）。
- 代码生成质量依赖任务说明是否完整；只填写，不自动提交考试。
