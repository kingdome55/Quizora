# 题灵 Quizora v0.7.7

> 发布日期：2026-11-03 · 类型：新功能（头歌查看限制解除）

## 一、调研与参考

头歌前端把“参考答案 / 评论 / 测试集”等入口的可见性放在任务详情 JSON 的字段里，页面渲染时读取这些字段决定是否展示：

| 字段 | 作用 | 解除值 |
| --- | --- | --- |
| `has_answer` | 是否存在答案入口 | `true` |
| `challenge.hide_answer` | 是否隐藏「参考答案」标签 | `false` |
| `game.homework_common_answer_open` | 是否禁止查看答案 | `false` |
| `game.answer_open` | 是否已开放答案 | `1` |
| `game.homework_common_comment_open` | 是否禁止查看评论 | `false` |
| `shixun.is_disable_discuss` | 是否隐藏评论入口 | `false` |
| `shixun.test_set_permission` | 是否允许解锁测试集 | `true` |
| `shixun.open_answer_and_test` | 测试集/答案联调开关 | `1` |
| `shixun.show_code_dir` | 是否显示代码目录 | `true` |
| `shixun.display_git_address` | 是否显示 Git 地址 | `true` |

参考实现：

- `lcandy2/user.js` —《头歌复制助手 EduCoder Copy Helper》：`document_start` hook `window.fetch`，改写 `/api/tasks` 返回的 `shixun/challenge` 权限字段（AGPL-3.0，仅参考行为，未复制代码）。
- `lcandy2/user.js` —《头歌助手 EduCoder Helper》：参考答案面板走平台官方 `get_answer_info.json` / `unlock_answer.json`，并明确提示“会留下查看记录 / 消耗积分”。
- 头歌前端 bundle 与保存的任务 JSON：确认上述字段名及页面渲染条件。

## 二、0.7.7 实现

- `src/content/edu-paste.js` 在原有 MAIN world `fetch` hook 中新增 `patchTaskView()`：
  - 任务详情 JSON 置 `has_answer=true`、`view_answer_tip=false`；
  - 改写 `game / challenge / shixun` 的查看入口字段（见上表）；
  - 保留原有 copy/paste 字段改写。
- 页面收到改写后的任务 JSON 后，会重新渲染出「参考答案 / 记录 / 评论 / 测试集 / 代码目录 / Git 地址」入口。
- `edu-paste-ready.js` 监听 MAIN world 的 `VIEW_UNLOCKED` 消息，将页面徽标与侧边栏状态更新为“粘贴/查看限制已解除（含参考答案入口）”。
- `background.js` 新增 `EDU_VIEW_UNLOCKED` 状态与日志。
- 控制台新增查看接口摘要：`status / entries / content / cost`，便于真机判断是“接口拒绝”还是“答案未解锁”。

## 三、边界

- 参考答案正文仍由平台官方接口返回；若平台要求金币或留下查看记录，页面会照常提示。插件**不伪造答案、不修改金币/成绩、不修改评测状态**。
- 考试页（路径含 `/exam`）继续硬性跳过，不注入查看/粘贴解锁逻辑。
- 若任务数据通过 XHR 而不是 fetch 加载，当前 hook 不覆盖；需要按真机网络情况补 XHR hook。
