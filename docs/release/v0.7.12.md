# 题灵 Quizora v0.7.12

> 发布日期：2026-11-03 · 类型：面板精简 + AI 服务繁忙处理

## 一、问题

截图日志显示：

```text
代码生成失败：HTTP 502: {"error":{"message":"Service is too busy..."}}
未通过：头歌 · 第1关未通过
```

这是模型服务端 502，不是代码写错。旧流程把 AI 接口失败当成答题失败，随后继续点评测，显示“未通过”。

同时侧边栏一次性展示模型连接、运行参数、学习通选项、头歌选项、状态、日志，视觉压力较大。

## 二、修复

### AI 服务繁忙

- LLM 429/500/502/503/504 重试间隔改为 3 秒 / 8 秒；
- 最终返回明确错误 `AI 服务繁忙（HTTP xxx）`；
- 头歌流程遇到该错误时停止并显示“AI 服务繁忙”，不再点评测、不再标记“未通过”。

### 面板精简

侧边栏改为：

1. **运行**：开始 / 停止 / 探测 / 清空缓存；
2. **状态**：站点、模式、题号、缓存；
3. **日志**；
4. **设置（折叠）**：模型、Key、答题间隔、学习通/头歌选项。

设置默认收起；未配置 API Key 时自动展开。卡片间距、圆角、阴影同步缩小。

## 三、验证

- 全量 JS 语法检查、构建通过：37 文件，296.5 KB，SHA256 `667176026EFE49E05C44D64D6297D3BEBB2D4878F01ADF701BEC3EE15342EF5D`。
- 0.7.11 可见 model 回退、写后回读、模板合并测试继续通过。

## 四、边界

- 502/503 是模型服务端问题，插件只能重试与提示，不能保证一定成功；可切换到 `deepseek-v4-pro` 或稍后重试。
