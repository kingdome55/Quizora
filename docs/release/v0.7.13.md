# 题灵 Quizora v0.7.13

> 发布日期：2026-11-03 · 类型：修复（CodeMirror 5 重复代码）

## 一、现象

日志：

```text
已写入代码（84 字符 · cm5 · cm5:0）
写入后可见编辑器未包含目标代码（52 字符），尝试 DOM 覆盖…
DOM 覆盖后可见编辑器仍未包含目标代码，停止评测
未通过：头歌 · 第1关未通过
```

编辑器出现两份模板和两份答案。

## 二、根因

`cm.setValue(code)` 已经返回 84 字符，说明写入成功；但写后回读使用 `.CodeMirror-code` 的 `innerText`，CodeMirror 5 只渲染可见行/虚拟行，读到 52 字符，误判“未包含目标代码”，触发 DOM 覆盖，结果又插入一份代码。

## 三、修复

1. 信任 `Monaco/CM5/CM6/Ace` 的 `setValue` 返回值与 `visible` 标记；只有写入目标 `visible=false` 时才做 DOM 兜底。
2. 不再用 CodeMirror `.CodeMirror-code` 虚拟行文本做精确校验。
3. `mergeWithTemplate` 遇到多组 `#代码开始/#代码结束` 时，保留第一组前缀与最后一组后缀，清理历史重复模板后再插入答案。
4. 0.7.12 的侧边栏精简、AI 502 服务繁忙处理继续保留。

## 五、真机验收

- 日志应为 `已写入代码（N 字符 · cm5 · cm5:0）`，不再出现“写后可见编辑器未包含目标代码”。
- 编辑器只保留一份 `use library;` / `#代码开始` / `#代码结束`，答案位于标记之间。
- 若仍出现重复，把 `已写入代码` 与 `编辑器：...` 日志发回。
