# 题灵 Quizora v0.5.5

本版本集中修复两类真实页面问题：填空题答案错乱/只填第一个，以及同一页面多个任务点只处理第一个。

## 修复内容

### 1. 填空题答案错乱、空填、只填第一个

- **禁用填空题答案缓存**：填空答案不再从历史缓存复用，避免一道题的答案被套到另一道题。
- **缓存校验**：选择题缓存增加题面、题型、空格数校验；旧格式缓存自动失效。
- **写入前重新查询 DOM**：不再使用扫描阶段缓存的输入框引用；页面重新渲染后仍能写入当前输入框。
- **写入后校验并补写**：等待 160ms 后重新读取输入值，缺失的框补写一次，全部有值才算完成。
- 保留 0.5.4 的合并答案拆分：`"甲；乙；丙"` 会拆成三个独立答案。

### 2. 同一页面多个任务点只答第一个

- 学习通启动时不再只选“题数最多的一个 frame”，而是同时启动**所有检测到题目的 frame**。
- 日志新增 `任务点分布：#1 12题，#2 3题` 与 `[任务点N]` 前缀。
- 任一任务点完成不会提前把整卷标记为完成；所有任务点结束后才汇总状态。
- 任一任务点手动停止会同时停止其余任务点。

## 安装

1. 下载 `quizora-v0.5.5.zip` 并完整解压。
2. `edge://extensions` → 开发人员模式 → 加载解压缩的扩展 → 选择 `quizora-v0.5.5`。
3. 重载扩展后刷新页面；建议先点一次“清空缓存”，再重新探测/开始。
