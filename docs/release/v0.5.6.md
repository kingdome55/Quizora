# 题灵 Quizora v0.5.6

本版本针对多空填空“只填第一个”与速度问题做了进一步修复。核心原因是：页面只暴露了第 1 个输入框（或在扫描时只看到 1 个），插件把空格数当成 1，模型自然只返回一个答案。

## 修复内容

- **空格数从题干推断**：统计题干中的 `____` 段数，即使页面只检测到 1 个输入框，也会向模型请求全部空的答案（如 3 个）。
- **扩展输入框作用域**：题目容器只包含部分输入框时，自动向上寻找同一题范围内其余输入框，避免只拿到第 1 个。
- **空框点击激活**：若其余空仍是“第 N 空：”占位框，写入前会依次点击，使页面创建输入框后再填写。
- **严格填空缓存**：只有题面、题型、空格数、答案数组长度全部一致才命中缓存，旧缓存不会再次污染答案。
- **单轮运行去重**：同一轮扫描内用 `processed` 集合跳过已处理题目，避免填空题被反复判题（这是“慢如蜗牛”的主要原因）。
- 缩短填空写入后的等待与补写间隔（160/120ms → 100/80ms）。

## 怎么确认修复生效

启动时日志会新增：

```
填空 #10：空格 3 / 输入框 3 / 空框 0
填空 #11：空格 2 / 输入框 2 / 空框 0
```

- `空格` 应等于题干里的空格数。
- `输入框` 应等于或接近空格数。
- 若 `空格 3 / 输入框 1 / 空框 0`，说明该页的其余空既不是输入框也不是可点击空框，需要真机 DOM 进一步定位。

## 安装

1. 下载 `quizora-v0.5.6.zip` 并完整解压。
2. `edge://extensions` → 开发人员模式 → 加载解压缩的扩展 → 选择 `quizora-v0.5.6`。
3. 重新加载扩展后刷新页面；建议先“清空缓存”，再探测/开始。
