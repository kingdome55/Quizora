# 题灵 Quizora v0.7.4

> 发布日期：2026-11-02 · 类型：恢复功能 + 平台标识

## 背景

0.7.3 把头歌自动答题停用，只保留粘贴解锁。用户明确要求：**不要删除已开发的功能**，恢复头歌自动答题，同时保留粘贴解锁，并把平台标识显示清楚。

## 0.7.4 改动

### 恢复

- manifest 重新注入头歌 `hud.js / edu-adapter.js / edu-main.js`（document_idle）；
- `sites.js` 头歌 files 恢复；`startRun` / `probe` 恢复正常的 frame 选择与自动答题；
- 0.7.0–0.7.2 的自动生成、Monaco/DOM 写入、评测重试、下一关、刷新续跑重新可用。

### 保留

- 0.7.3 的粘贴解锁继续生效（document_start MAIN world）：
  - 改写任务 API 的 `can_copy/forbid_copy/copy_for_exercise` 与 `challenge.diasble_copy`；
  - 清理 `onpaste`、恢复 `user-select:text`。
- 自动答题失败时，仍可直接粘贴自己的代码手动评测。

### 平台标识

- 侧边栏“站点”显示 **头歌（EduCoder）**；
- 新增“模式”行：**自动答题（实验）+ 粘贴解锁**；
- 页面右上角新增题灵·头歌徽标：
  - 空闲：`粘贴已解锁 · 自动答题可用（实验）`
  - 运行中：`自动答题运行中（实验）`
- HUD 与日志统一加“头歌”前缀：`头歌 · 第 1 关…`、`头歌 · 已通过 2 关…`。

## 验证

- 头歌两关自动答题 mock：第 1 关失败重试后通过，进入第 2 关并通过；状态“已完成 / 头歌 · 已通过 2 关”。
- 粘贴 API/DOM 解锁 mock：`forbid_copy=false`、`onpaste=null`、`user-select:text`。

## 使用

1. 加载 v0.7.4，打开头歌任务页；页面右上角出现“题灵 · 头歌（EduCoder）”徽标。
2. 可以直接粘贴自己的代码手动评测；
3. 也可以在侧边栏点“开始”，运行自动答题（实验）。自动答题停在某一关时，回到粘贴模式手动完成即可。

## 说明

- 头歌自动答题仍是实验能力：真实页面的编辑器识别/评测文案可能因平台改版失效；粘贴解锁是兜底。
- 考试页（`/exam`）不解锁粘贴，也不自动作答。
