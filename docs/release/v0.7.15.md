# 题灵 Quizora v0.7.15

> 发布日期：2026-11-03 · 类型：修复（仍选 dom-monaco / DOM 兜底找不到容器）

## 一、现象

0.7.14 日志：

```text
可选编辑器：dom-monaco@#0，cm5@#0
编辑器：dom-monaco · frame#0 · 未知语言 · 模板 52 字符
已写入代码（109 字符 · cm5 · cm5:0）
写入目标是隐藏编辑器，尝试 DOM 覆盖…
DOM 覆盖写入失败：未找到编辑器容器，停止评测
```

可见编辑器实际是 CodeMirror 5（`cm5`），但 `domFind` 先匹配 `.monaco-editor`，误选了一个不可见/非当前的 Monaco 容器。

## 二、修复

1. `domFind` 不再按选择器顺序返回第一个类型，而是遍历 `.monaco-editor` / `.cm-editor` / `.ace_editor` / `.CodeMirror` 等，按**屏幕内可见面积**取最大者。
2. `pickEditor` 增加视口过滤：排除 `bottom<=0`、`right<=0`、`top>=innerHeight`、`left>=innerWidth` 的屏幕外容器。
3. `findEduEditors` 排序改为“可见优先 → MAIN world API 优先”，同时存在 `dom-monaco` 和 `cm5` 时优先 `cm5`。
4. 背景 `EDU_SET_CODE` 对 `dom-*` 的 MAIN 写入结果，如果 `visible=false` 不再接受，改为向**正确 frame** 发送 `EDU_DOM_SET`，避免在 `edu-main` 所在 frame 找不到容器。
5. 0.7.14 的 `wr` 作用域修复继续保留。
