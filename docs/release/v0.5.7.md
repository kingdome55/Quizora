# 题灵 Quizora v0.5.7

本次修复对应真机日志 `空格 3 / 输入框 0 / 空框 3` 的场景：页面上的填空位不是现成 `<input>`，而是点击后才激活的空框。

## 修复内容

- **先激活再判断**：0.5.6 在“输入框为 0”时提前返回，根本没有执行空框点击逻辑；0.5.7 先点击空框，再重新收集输入框。
- **按第 N 空逐槽处理**：优先使用当前可见的第 N 个输入框；没有时点击对应“第N空”空框，并把答案写入点击后获得焦点的输入框或可编辑区。
- **点击事件兼容**：同时派发 `pointerdown`、`mousedown`、`mouseup`、`click`，覆盖只监听鼠标按下的页面。
- **不再假报已填**：只有实际写入成功的空数量达到答案数量才标记完成；如果空框无法激活，会显示“部分空未填/失败”，而不是“已填”。

## 安装

1. 下载 `quizora-v0.5.7.zip` 并完整解压。
2. `edge://extensions` → 开发人员模式 → 加载解压缩的扩展 → 选择 `quizora-v0.5.7`。
3. 重新加载扩展后刷新页面；建议先“清空缓存”，再探测/开始。
