# 题灵 Quizora v0.7.10

> 发布日期：2026-11-03 · 类型：头歌答案格式修复 + 无记录读取

## 一、答案格式问题

截图对比：

初始模板：

```sql
use library;
#代码开始

#代码结束
```

参考答案面板内容：

```sql
insert into reader(xm,dhhm) values("林团","13507311234");
```

旧逻辑直接把“参考答案片段”覆盖整个编辑器，导致：

```sql
insert into reader(...); use library;
#代码开始
#代码结束
```

答案跑到 `use library;` 前面，模板结构被破坏，评测自然不匹配。

## 二、修复

- 新增 `mergeWithTemplate(template, code)`：
  - 若当前编辑器含 `#代码开始` / `#代码结束`，把答案片段插入两个标记之间；
  - 保留 `use library;` 与模板其它内容；
  - 答案自身已是完整代码（含两个标记）时原样写入；
  - 无模板时去掉重复的 `use library;`。
- `dom-monaco` 写入时优先尝试 MAIN world 的 Monaco/CM/Ace API 覆盖式 `setValue`，失败再走 `insertText` 兜底。
- 期望结果：

```sql
use library;
#代码开始
insert into reader(xm,dhhm) values("林团","13507311234");
#代码结束
```

## 三、无金币 / 无记录读取

技术上，平台**未解锁**的参考答案属于服务端授权/金币逻辑，插件无法保证零金币/零记录直接拿到。0.7.10 改为“默认不主动触发”：

1. 启动时优先读取页面**已显示**的 `.answer-content`；
2. 其次读取本标签页 `sessionStorage` 缓存（`watchVisibleAnswer` 会在你手动打开答案面板时自动缓存）；
3. 有内容直接使用，**不调用** `get_answer_info` / `unlock_answer`，不新增查看记录；
4. 未命中时默认回退 AI 生成，不主动调用平台接口；
5. 侧边栏新增开关“只读已显示/缓存答案，不主动调用查看接口（避免金币/记录）”，默认开启；关闭后才恢复平台接口，自动解锁仍需单独勾选。

注意：如果你手动在页面查看未解锁答案，平台仍可能扣金币/留下查看记录；这不是插件能绕过的服务端逻辑。
