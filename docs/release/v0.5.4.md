# 题灵 Quizora v0.5.4

本次为缺陷修复版本，重点解决学习通“一题多个空”的填空题写入问题，以及刷新后整卷被误判为“已作答”的问题。

## 修复内容

### 1. 多空填空只填第 1 空 / 答案被塞进第 1 空

- 模型有时把多个空的答案合并成一个字符串（如 `"甲；乙；丙"`），旧逻辑会整段写入第 1 个输入框。
- 现在会在服务端与写入端各做一次拆分：按 `；`、`;`、`、`、`|`、`／` 或换行拆成与空格数量一致的数组，再逐框写入。
- 提示词明确要求 `blanks` 每个元素只对应一个空，禁止用分隔符合并。
- 写入后逐框校验，全部框有值才算 `complete`。

### 2. 部分填空被当作“已完成”

- 填空题的已答判断由“任意一个框有值”改为“**全部空格有值**”。
- 只填了第 1 空时不会再被跳过。

### 3. 刷新后 0/12 全部“跳过”

- 跳过逻辑不再使用容器 class 正则（`done|answered|complete|finished|saved`）和历史 `doneKeys`，仅依据当前 DOM 的真实作答状态。
- 页面刷新丢失草稿后，空输入框会重新作答，而不是全部误跳。

## 安装

1. 下载 `quizora-v0.5.4.zip` 并完整解压。
2. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启“开发人员模式”。
3. “加载解压缩的扩展” → 选择解压后的 `quizora-v0.5.4` 目录。
4. 重载扩展后，刷新答题页面并重新探测。

详细步骤见 `docs/INSTALL.md`。
