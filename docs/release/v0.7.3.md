# 题灵 Quizora v0.7.3

> 发布日期：2026-11-02 · 类型：功能调整（头歌改为粘贴解锁）

## 为什么调整

自动生成代码的一次性正确率偏低，且错一个测试点就卡关，不满足实际使用。按用户要求退回“让头歌编辑器可以粘贴你自己的代码”，只解除粘贴限制，不自动生成、不自动评测。

## 0.7.3 实现

- **平台级解锁**（MAIN world，`document_start`，`all_frames`）：hook `window.fetch`，改写任务 API（`/api/tasks`、`json?homework_common_id`）返回的：
  - `shixun.can_copy = true`、`forbid_copy = false`、`copy_for_exercise/copy_for_exercise_save/active_copy = true`
  - `challenge.diasble_copy / disable_copy = false`
- **编辑器级解锁**：递归清理 `input / textarea / [contenteditable] / .monaco-editor / .cm-editor / .ace_editor / .CodeMirror` 的 `onpaste`，恢复 `user-select:text`；MutationObserver + 短轮询覆盖动态编辑器。
- 面板显示“头歌粘贴模式：请直接粘贴代码并手动评测”；考试页（`/exam`）不解锁。

参考：EduCoder Copy Helper（MIT 兼容行为，未复制代码）的 `can_copy / forbid_copy / diasble_copy` 修改点。

## 验证

- 本地 mock：任务 API 返回 `forbid_copy:true` 时，改写后 `can_copy=true / forbid_copy=false`；`document.onpaste` 与编辑器 `onpaste` 清空，`user-select:text` 生效。

## 使用

1. 加载 v0.7.3，打开头歌任务页（可直接打开或学习通内嵌）。
2. 日志出现“头歌：粘贴限制已解除”。
3. 在右侧编辑器粘贴你的代码（Ctrl+V / 右键粘贴均可），手动点“评测”。
4. 不用时可在 `edge://extensions` 停用扩展。

## 限制

- 考试页（URL 含 `/exam`）不解锁。
- 若平台改版字段名（如改用 `allow_copy`），需按新字段补充。
