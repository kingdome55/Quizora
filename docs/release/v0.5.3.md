# 题灵 Quizora v0.5.3

首个公开测试版（Beta）。本次发布完成品牌统一、仓库工程化与安装包构建，并包含学习通简答题跨 frame 写入修复。

## 亮点

- 品牌统一为「题灵 / Quizora」，新增 16 / 48 / 128 品牌图标。
- 新增 GitHub 工程文件：README、MIT LICENSE、CHANGELOG、CONTRIBUTING、SECURITY、Issue/PR 模板。
- 新增生产构建脚本 `scripts/build.ps1`，生成可加载的扩展目录与 ZIP 安装包。
- 修复学习通简答题跨 frame 写入抛 `Illegal invocation` 的问题：
  - 每帧只上报自身文档的题目；
  - frame 选择在题数相同时优先更深层 frame；
  - 原生 value setter 按元素所属 realm 获取；
  - 单题写入异常不再中断整卷。

## 支持范围

- 浏览器：Microsoft Edge（Chromium）/ Google Chrome（Side Panel，建议 114+）。
- 站点：学习通（`*.chaoxing.com`）、Wayground / Quizizz、任意 http/https 网页。
- 题型：单选、多选、判断、填空、简答/论述/名词解释、图片题（最多 2 张）。
- 不支持：连线、拖拽、编程题、听力题；Wayground 多选与图片题。

## 安装

1. 下载 `quizora-v0.5.3.zip` 并完整解压。
2. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启“开发人员模式”。
3. “加载解压缩的扩展” → 选择解压后的 `quizora-v0.5.3` 目录（内含 `manifest.json`）。
4. 打开侧边栏，填写 API Base URL、Key、模型，测试连接。
5. 先开“演练模式”核对，再关闭并“开始”。

详细步骤见 `docs/INSTALL.md`；已知问题见 `docs/KNOWN_ISSUES.md`。

## 已知限制

- 学习通字体反爬会导致题干/选项出现乱码，影响判题准确率（未解决）。
- 题目分散在多个兄弟 frame 时只会处理其中一个 frame。
- 自动答题可能违反平台规则；本项目不自动提交，也不做风控规避。
