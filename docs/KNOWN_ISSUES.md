## 2. 重点问题说明

### K1（P0）0.5.3 简答修复未验证

- **现状**：0.5.2 真机在最后一题（简答）报 `停止：运行异常：Illegal invocation`，整卷停在 10/11。0.5.3 已做四项修复（同文档过滤、深度优先、realm-safe setter、单题容错），但**没有真机结果**。
- **风险**：如果根因还有别的跨 realm 原生调用（例如 `getComputedStyle`、UEditor 实例方法），问题会以不同错误复现。
- **验收**：真机 11/11，简答编辑区有内容，日志无异常。
- **若失败**：抓取 `第 11 题写入异常：…` 与 `第 11 题[short] 失败（…）` 两行，按错误类型继续修。

### K2（P1）字体反爬乱码

- **现状**：学习通部分页面用自定义字体把随机码位映射为正确字形；`innerText` 得到“庝/庡/庤”等字符。识别层不受影响，但模型看到的题干是乱码。
- **影响**：答案准确率不可控，且会污染缓存键与已答 key。
- **0.6.0 实施**：选用成熟开源方案（OCSJS / 超星字体解密，同一份 MIT 映射表）：Typr.js 解析内嵌 TTF，按 `glyphToPath` 的 MD5 查表，构建码位映射；扫描与探测前等待字库就绪；未命中时回退原文。
- **剩余风险**：映射表与当前学习通字体版本不匹配时 `mapped=0`，日志会显示“字体解密已就绪”缺省；需按失败样本更新表。
- **验收**：真机日志出现“字体解密已就绪：N 个字形”，且探测题干为正常汉字。

### K20（P1）头歌粘贴解锁真机未验证

- **现状**：0.7.3 起 hook 任务 API + 清理 `onpaste`；0.7.4 恢复自动答题但保留粘贴解锁；本地 mock 验证字段与 DOM 解锁生效。
- **风险**：平台若改用 XHR、或字段名变化（如 `allow_copy`），解锁不生效；考试页按 `/exam` 拒绝。
- **验收**：真机日志出现“头歌：粘贴限制已解除”，编辑器中 Ctrl+V 能粘贴自己的代码。
- **失败处理**：确认页面是否用 `fetch` 拉取 `/api/tasks`；把 DevTools Network 中该请求的响应字段（脱敏）发回。

### K21（P1）头歌查看限制解除真机未验证

- **现状**：0.7.7 在任务 JSON 中改写 `has_answer`、`hide_answer`、`homework_common_answer_open`、`answer_open` 等查看入口字段；VM mock 17 项断言通过。0.7.8 已补 XHR hook。
- **风险**：平台服务端可能仍拒绝参考答案接口，或要求金币/留下查看记录。
- **验收**：真机出现「参考答案」标签，控制台输出 `[题灵] 头歌查看接口 ... status=... entries=... content=... cost=...`；已解锁答案能正常显示。
- **失败处理**：把该接口的 `status/entries/content/cost`（不要贴答案正文或个人信息）与 Network 请求类型发回。

### K22（P1）头歌参考答案签名/自动解锁真机未验证

- **现状**：0.7.8 通过 XHR 采集任务 ID/`Pc-Authorization`，用 `md5(base64("method=GET&ak=...&sk=...&time=..."))` 调用 `get_answer_info`；签名与 Node crypto 一致。
- **风险**：本机时间偏差导致 `status=-102`；`data.educoder.net` 的 CORS 不允许自定义头；参考答案未解锁且未开启自动解锁。
- **验收**：启动日志出现 `已读取平台参考答案（N 字符 · 名称）` 与 `使用平台参考答案写入（N 字符）`。
- **失败处理**：确认 Windows 时间同步；把控制台 `[题灵] 头歌查看接口 ... status=...` 与启动日志发回，不要贴答案正文。

### K16（P1）头歌真实 DOM 未验证（自动答题，已停用）

- **现状**：0.7.2 已支持 MAIN world 跨 frame 扫描，并在 sandbox/跨域 iframe 无法注入时回退到内容脚本 DOM 探测（同源 iframe、open shadow DOM）；真实头歌的按钮文案、结果面板层级仍为文本+几何启发式。
- **风险**：编辑器识别不到、找不到“评测”按钮或把“评测记录”误当按钮；结果关键词不匹配导致重试耗尽。
- **验收**：真机日志出现 `编辑器：monaco/ace/cm5/cm6 · frame#N`、“已写入代码”“评测返回：…”“评测通过”，并通过至少 2 关。
- **失败处理**：把探测快照的 `buttons`、`result`、`hasEditor/hasEvaluate` 与日志原文发回，按真实文案补匹配；不要把整页 HTML 直接贴出（可能含个人信息）。

### K17（P2）头歌多文件任务

- **现状**：Monaco 有多个 model 时只选内容最长的一个写入。
- **风险**：需要同时修改多个文件的任务只完成主文件，评测不通过。
- **方案**：`EDU_STATE` 返回全部模型，`askCode` 改为返回 `{uri: code}` 映射，逐个 `setValue`；需要真实多文件样本。

### K18（P1）头歌跳转/刷新续跑未验证

- **现状**：通过 `sessionStorage` 保存 `{settings, passed}`（不含 API Key），刷新后自动继续；SPA 无刷新跳转则原流程继续。
- **风险**：整页刷新后 background 的运行态会被 `tabs.onUpdated` 重置；续跑依赖内容脚本自行上报状态，面板可能短暂显示“页面已切换”。
- **验收**：真机通过一关后手动刷新，确认自动继续且不重复作答。

### K4（P1）多 frame 分摊题目

- **现状**：`pickFrame` 只选一个最优 frame 并只向它发 `WG_START`；同一份卷子的题如果分散在多个兄弟 frame（例如每张卡片一个 iframe），只能答其中一个。
- **证据**：架构如此；目前学习通样本是“整卷在一个 frame 内”，未触发。
- **方案**：按 frame 维护运行清单，向每个“有题”的 frame 各发一次 `WG_START`，共享去重 key 与进度；需要解决 HUD 只保留一个、停止广播、重复题目去重。
- **风险**：父/子 frame 同时看到同一批题（已用同文档过滤缓解）仍可能重复，需要全局 key 去重。

### K6（P2）死代码

- `src/content/main.js:223` 仍读取 `settings.pauseOnLowConfidence` 与 `settings.confidenceThreshold`，但面板与默认配置已不再提供这两个字段；分支永不进入。
- `src/content/solver.js:22` 的 `confidenceThreshold` 也不再被外部配置。
- **建议**：删除分支与字段，避免后续误以为功能仍存在。

### K8（P2）权限与密钥

- `host_permissions` 覆盖 `https://*/*` 与 `http://*/*`，权限面很大；
- manifest 没有 `optional_host_permissions`，但面板调用 `chrome.permissions.request`；
- API Key 明文存于 `chrome.storage.local`（未加密）。
- **建议**：若长期使用/上架，收窄为 `optional_host_permissions` + 按需授权；文档明确“共用电脑不要保存 Key”。

### K10（P2）已答 key 不稳定

- `doneKeys` 使用 `type|stem|options` 的 hash；题干乱码时每次页面加载可能不同（若加密随机化），导致跳过失效。
- `DONE_KEY` 使用完整 `search`，一次性 token 变化会新建空集合。
- **建议**：改用 URL 的稳定部分（如 `workId`/`chapterId`）+ 题号/选项序号的弱 key；或提供“本次会话内跳过”的内存模式。

### K11（P2）UEditor 兼容

- 当前多路写入已覆盖常见形态，但：
  - 同页多个编辑器时，`UE.instants` 定位依赖“容器包含”；
  - `save(q)` 只找文字**恰好等于“保存”**的按钮，文案变化（“暂存”“保存答案”）会漏；
  - 部分版本需要显式 `editor.sync()`。
- **验收**：至少覆盖 2 种学习通版本的真实页面。

## 3. 其它风险

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 页面/浏览器更新 | 学习通与 Wayground 改版会让选择器失效 | 三路锚定 + 探测诊断 + 快速补选择器 |
| 扩展重载后旧页面失效 | 内容脚本上下文失效，探测无响应 | 面板提示 + 静态脚本（新页面即生效） |
| 浏览器站点访问权限 | Edge 若把扩展设为“点击时允许”，静态脚本不生效 | 自检日志会显示注入失败；文档提示检查站点权限 |
| 模型接口变化 | Base URL/模型名/JSON 模式差异 | 400 自动降级、401/403/404 明确报错、可自定义模型 |
| 演练模式误关 | 直接写入真实考试 | 默认开启；文档强调先演练 |
| 交卷误触 | 自动提交不可逆 | 代码不点交卷；只点“保存” |
| 缓存污染 | 乱码题干或错误答案被缓存 | 面板可清空缓存；简答不缓存 |

## 4. 技术债务清单（按处理顺序）

3. 删除 `pauseOnLowConfidence` / `confidenceThreshold` 死代码；
4. 增加“导出诊断”按钮（复制/下载 JSON），减少排障往返；
5. 收窄权限或补 `optional_host_permissions`；
6. 量化大页面探测耗时，必要时给 `labelBlocks/controlBlocks` 加节点上限或缓存；
7. 记录学习通/Wayground 的真实 DOM 样本（脱敏）作为回归夹具。
