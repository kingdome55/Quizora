## 2. 重点问题说明

### K1（P0）0.5.3 简答修复未验证

- **现状**：0.5.2 真机在最后一题（简答）报 `停止：运行异常：Illegal invocation`，整卷停在 10/11。0.5.3 已做四项修复（同文档过滤、深度优先、realm-safe setter、单题容错），但**没有真机结果**。
- **风险**：如果根因还有别的跨 realm 原生调用（例如 `getComputedStyle`、UEditor 实例方法），问题会以不同错误复现。
- **验收**：真机 11/11，简答编辑区有内容，日志无异常。
- **若失败**：抓取 `第 11 题写入异常：…` 与 `第 11 题[short] 失败（…）` 两行，按错误类型继续修。

### K2（P1）字体反爬乱码

- **现状**：学习通部分页面用自定义字体把随机码位映射为正确字形；`innerText` 得到“庝/庡/庤”等字符。识别层不受影响，但模型看到的题干是乱码。
- **影响**：答案准确率不可控，且会污染缓存键与已答 key。
- **可能方案**（尚未实施）：
  1. 每题截图 → 视觉模型 OCR（成本高、速度慢）；
  2. 解析页面加载的字体文件（cmap/字形轮廓）建立码位→真实字的映射；
  3. 只对“高乱码比例”的题目启用截图兜底。
- **建议**：先做小样本验证（同一题：innerText vs 截图 OCR），再决定是否接入。

### K4（P1）多 frame 分摊题目

- **现状**：`pickFrame` 只选一个最优 frame 并只向它发 `WG_START`；同一份卷子的题如果分散在多个兄弟 frame（例如每张卡片一个 iframe），只能答其中一个。
- **证据**：架构如此；目前学习通样本是“整卷在一个 frame 内”，未触发。
- **方案**：按 frame 维护运行清单，向每个“有题”的 frame 各发一次 `WG_START`，共享去重 key 与进度；需要解决 HUD 只保留一个、停止广播、重复题目去重。
- **风险**：父/子 frame 同时看到同一批题（已用同文档过滤缓解）仍可能重复，需要全局 key 去重。

### K6（P2）死代码

- `src/content/main.js:223` 仍读取 `settings.pauseOnLowConfidence` 与 `settings.confidenceThreshold`，但面板与默认配置已不再提供这两个字段；分支永不进入。
- `src/content/solver.js:22` 的 `confidenceThreshold` 也不再被外部配置。
- **建议**：删除分支与字段，避免后续误以为功能仍存在。

### K8（P2）权限与密钥

- `host_permissions` 覆盖 `https://*/*` 与 `http://*/*`，权限面很大；
- manifest 没有 `optional_host_permissions`，但面板调用 `chrome.permissions.request`；
- API Key 明文存于 `chrome.storage.local`（未加密）。
- **建议**：若长期使用/上架，收窄为 `optional_host_permissions` + 按需授权；文档明确“共用电脑不要保存 Key”。

### K10（P2）已答 key 不稳定

- `doneKeys` 使用 `type|stem|options` 的 hash；题干乱码时每次页面加载可能不同（若加密随机化），导致跳过失效。
- `DONE_KEY` 使用完整 `search`，一次性 token 变化会新建空集合。
- **建议**：改用 URL 的稳定部分（如 `workId`/`chapterId`）+ 题号/选项序号的弱 key；或提供“本次会话内跳过”的内存模式。

### K11（P2）UEditor 兼容

- 当前多路写入已覆盖常见形态，但：
  - 同页多个编辑器时，`UE.instants` 定位依赖“容器包含”；
  - `save(q)` 只找文字**恰好等于“保存”**的按钮，文案变化（“暂存”“保存答案”）会漏；
  - 部分版本需要显式 `editor.sync()`。
- **验收**：至少覆盖 2 种学习通版本的真实页面。

## 3. 其它风险

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| 页面/浏览器更新 | 学习通与 Wayground 改版会让选择器失效 | 三路锚定 + 探测诊断 + 快速补选择器 |
| 扩展重载后旧页面失效 | 内容脚本上下文失效，探测无响应 | 面板提示 + 静态脚本（新页面即生效） |
| 浏览器站点访问权限 | Edge 若把扩展设为“点击时允许”，静态脚本不生效 | 自检日志会显示注入失败；文档提示检查站点权限 |
| 模型接口变化 | Base URL/模型名/JSON 模式差异 | 400 自动降级、401/403/404 明确报错、可自定义模型 |
| 演练模式误关 | 直接写入真实考试 | 默认开启；文档强调先演练 |
| 交卷误触 | 自动提交不可逆 | 代码不点交卷；只点“保存” |
| 缓存污染 | 乱码题干或错误答案被缓存 | 面板可清空缓存；简答不缓存 |

## 4. 技术债务清单（按处理顺序）

1. 把 mock 与验证脚本迁入 `tests/`，并提供 `npm` 脚本或 PowerShell 脚本一键跑；
2. `git init` + 首次提交 + 给 0.5.3 打 tag；
3. 删除 `pauseOnLowConfidence` / `confidenceThreshold` 死代码；
4. 增加“导出诊断”按钮（复制/下载 JSON），减少排障往返；
5. 收窄权限或补 `optional_host_permissions`；
6. 量化大页面探测耗时，必要时给 `labelBlocks/controlBlocks` 加节点上限或缓存；
7. 记录学习通/Wayground 的真实 DOM 样本（脱敏）作为回归夹具。
