# 题灵（Quizora）— 项目概况与当前状态

> 审计日期：2026-10-31 · 工作树版本：0.5.8 · 最近真机验证：0.5.2（部分通过）

## 1. 项目定位

`wayground-auto` 是一个 **Edge / Chrome Manifest V3 扩展**，在**已经打开**的答题页面上通过侧边栏触发：

1. 扫描整页题目（或当前单题）；
2. 调用 OpenAI 兼容接口的大模型判题；
3. 自动点击选项 / 写入填空与简答；
4. **不自动提交**，由用户检查后手动交卷。

支持三类站点：

| 站点 | 匹配规则 | 运行模式 |
| --- | --- | --- |
| Wayground / Quizizz | `wayground.com` / `quizizz.com` 的 `game/play/activity/join` 路径 | 单题状态机，跟随页面自动推进 |
| 学习通（超星） | 任意 `*.chaoxing.com` 页面 | 整卷扫描 + 逐题填写 + 每题保存（不交卷） |
| 通用网页 | 任意 `http/https` 页面 | 同学习通的整卷扫描与填写能力，作为兜底 |

```

│  │  ├─ cx-generic.js            # 通用控件反推
│  │  ├─ cx-plain.js              # 纯文本 A/B/C/D 选项
│  │  ├─ cx-adapter.js            # 整卷扫描（核心）

│  │  ├─ cx-fill.js               # 选项/填空/简答写入与标记
│  │  └─ cx-main.js               # 整卷调度、跳过、保存、HUD
│  ├─ panel.html / panel.css / panel.js       # 侧边栏
```

## 6. 边界与合规声明

- **不自动提交**：学习通填完后 HUD/日志提示“请检查后手动提交”；本工具不会点交卷。
- 不做自动加入对局、多账号、绕过监考/风控；不做切屏规避。
- API Key 明文存于 `chrome.storage.local`，仅限本机使用。
- 自动答题可能违反平台规则，账号与成绩风险由使用者承担。
- 扩展当前 `host_permissions` 覆盖全部 http/https 站点（为通用站点兜底），属于开发期取舍，见 KNOWN_ISSUES。
