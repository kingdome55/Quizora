# 安装与更新指南

> 适用于题灵（Quizora）0.7.4。安装前请确认浏览器为较新的 Edge / Chrome（支持 Manifest V3 与 Side Panel）。

## 1. 安装包结构

发布包 `quizora-v0.7.4.zip` 解压后应得到：

```
quizora-v0.7.4/
├─ manifest.json
├─ README.md
├─ CHANGELOG.md
├─ LICENSE
├─ assets/            icon16.png / icon48.png / icon128.png
└─ src/               background、content、panel 等源码
```

**不要把 ZIP 直接拖进浏览器**。必须先完整解压，再让扩展管理页加载解压后的目录。

## 2. Microsoft Edge 安装

1. 下载 `release/quizora-v0.7.4.zip`。
2. 右键解压到固定目录，例如 `D:\Quizora\`。
3. 打开 `edge://extensions`。
4. 打开页面左下角的“开发人员模式”。
5. 点击“加载解压缩的扩展”，选择 `D:\Quizora\quizora-v0.7.4`（该目录内应直接看到 `manifest.json`）。
6. 在工具栏找到“题灵”图标；若被折叠，点击拼图图标并固定。
7. 点击图标打开侧边栏。

## 3. Google Chrome 安装

步骤与 Edge 相同，扩展管理页改为 `chrome://extensions`。

要求：

- Chrome 建议 114 及以上（Side Panel API）。
- 同样需要开启“开发者模式”，并使用“加载已解压缩的扩展”。

## 4. 首次配置

1. 侧边栏打开“模型连接”。
2. 填写：
   - **API Base URL**：默认 `https://api.deepseek.com/v1`；
   - **API Key**：你的模型服务 Key；
   - **模型**：默认 `deepseek-flash`，可切换或自定义。
3. 点“保存”。
4. 点“测试连接”，日志出现“连接正常”即为成功。
5. 可选：点“测试图形”，验证视觉模型是否可用。

> Key 仅保存在本机 `chrome.storage.local`，不会上传到本项目的服务器（项目没有服务器）。

## 5. 使用前检查

1. 打开答题页面并保持标签页激活。
2. 点“探测当前页”：
   - 能看到题目数、题型分布与前 8 题；
   - 题干、选项与页面一致；
   - 若为 0 题，先看 `docs/TROUBLESHOOTING.md`。
3. 保持“演练模式”先跑一遍，核对建议。
4. 关闭演练后点“开始”。
5. 填完后**手动检查并提交**，扩展不会自动交卷。

## 6. 更新

1. 下载新版本 ZIP 并解压，覆盖旧目录（或解压到新目录）。
2. `edge://extensions` 中找到题灵，点“重新加载”。
3. 关闭并重新打开侧边栏。
4. 回到答题页面按 `Ctrl+F5` 刷新。
5. 重新点“探测当前页”。

> 扩展重新加载后，**已经打开的页面里旧内容脚本会失效**，必须刷新页面。

## 7. 卸载

- `edge://extensions` → 题灵 → “移除”。
- 如需清除本地配置与缓存：移除扩展会一并删除 `chrome.storage.local` 数据；也可在移除前点侧边栏“清空缓存”。

## 8. 安装后自检

| 检查项 | 期望 |
| --- | --- |
| 扩展管理页版本 | 0.7.4 |
| 工具栏图标 | 紫蓝渐变 + 白色对勾气泡 |
| 侧边栏标题 | 题灵 Quizora |
| 测试连接 | 返回有效下标与置信度 |
| 探测学习通页面 | 题目数 > 0（页面确有题目时） |

## 9. 常见安装问题

| 现象 | 处理 |
| --- | --- |
| “加载解压缩的扩展”报 manifest 缺失 | 选择到了 ZIP 或上一级目录；应选择含 `manifest.json` 的目录 |
| 安装后没有侧边栏 | 浏览器版本过旧或未固定图标；更新浏览器后重试 |
| 点“开始”提示不是支持的页面 | 确认当前标签页是学习通/Wayground/含题网页，且处于激活状态 |
| 探测无响应 | 扩展重载后未刷新页面；`Ctrl+F5` 后重试 |
| 测试连接 401/403 | Key 错误或无权限；404 检查 Base URL 是否缺少 `/v1` |
| 提示未授权 API 域名 | 检查扩展站点访问权限；或在 `edge://extensions` 中允许该域名 |

## 10. 安全提示

- 不要在共用电脑保存 API Key。
- 不要把 Key、Cookie、带个人参数的 URL 发到 Issue 或截图。
- 自动答题可能违反平台规则；请仅在自测、复习、模拟场景使用。
